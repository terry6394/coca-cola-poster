Best fits the dual deliverable of a beautiful poster and a memorable one-page HTML experience. A. Heritage Poster

Swiss / print editorial. Red, white, black, Georgia Green. A single poster that reads instantly.

  • Palette: Coke red, warm white, near-black, Georgia Green.
  • Typography: Playfair Display + Inter; original SVG lettering.
  • Motion: Scroll reveals, subtle parallax. Reduced-motion: static.
  • Complexity: Low–Medium
  • Risk: May feel conservative; mitigated by bold scale.

B. Dynamic Ribbon

Kinetic brand system. A fluid ribbon threads through the viewport, bubbles rise with scroll.

  • Palette: Coke red, white, black, silver bubbles.
  • Typography: Manrope / Satoshi; oversized numerals.
  • Motion: Canvas/SVG path morph, mouse parallax. Reduced-motion: static curves.
  • Complexity: High
  • Risk: Heavy on low-end devices; needs tight budget.

C. Brutalist Pop

Raw collage poster. Overlapping blocks, torn edges, marquees, pop-art nostalgia.

Implementation plan — Heritage Poster

Information hierarchy

  1. Headline: "Delicious & Refreshing"
  2. Year: "1886"
  3. Original contour-inspired bottle SVG
  4. Origin statement (≤25 words)
  5. Historical fact rail + disclaimer

Sections

  • Poster stage: 100vh composition.
  • Context panel: scroll-revealed brand context.
  • Footer: disclaimer, sources, credits.

Animation states

  • Load: headline + date fade up.
  • Scroll: bottle parallax, red disc scale.
  • Hover: fact-rail color inversion.
  • Reduced motion: all layout static.

Responsive breakpoints

  • Desktop ≥1280px: 12-column poster grid.
  • Laptop 1024–1279px: tighter grid.
  • Tablet 768–1023px: centered headline, bottle below.
  • Mobile <768px: single-column scroll.

Performance budget

  • Total page weight ≤350 KB.
  • FCP ≤1.2s, LCP ≤1.8s on 4G.
  • Only transform/opacity animations.
  • No external images except self-hosted fonts.

Accessibility requirements

  • Semantic HTML5 + heading hierarchy.
  • WCAG 2.1 AA color contrast.
  • aria-label on bottle SVG.
  • Skip link, focus-visible styles.
  • prefers-reduced-motion honored.
